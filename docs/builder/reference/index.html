Row types

Section titled “Row types”
Row Tab Columns
Check After response On, Source, Path, Compare, Expected
Extract After response On, Source, Path, Save as, Target, Secret, If missing
Set header Before request On, Name, Value
Remove header Before request On, Name
Set query param Before request On, Name, Value
Set variable Before request On, Name, Value, Target, Secret
Skip if Before request On, Variable, Operator, Value, Reason

Sources (Check and Extract)

Section titled “Sources (Check and Extract)”
Source Path Value type
Status — Number
Status text — Text
Time — Number (ms, 0.1 ms precision)
Size — Number (bytes)
Header Header name Text (first header of the name)
Cookie Cookie name Text
JSON body JSON path JSON value
XML body XPath subset Text
Regex Regex Text (group 1, or the complete match)
Text — Text (the complete body)

Section titled “Check operators”
Operator Takes a value Line form
equals Yes == or =
does not equal Yes !=
less than Number (Time: ms/s; Size: B/KB/MB) <
at most Number <=
greater than Number >
at least Number >=
contains Text contains
does not contain Text !contains
matches regex Regex —
exists No exists
does not exist No !exists
is empty No —
is not empty No —
length equals Whole number JSON path.length ==
length greater than Whole number JSON path.length >
length less than Whole number JSON path.length <
is type number, text, true/false, array, object, null —
is one of Comma-separated values —

Extract options

Section titled “Extract options”
Option Values Default
Target Environment, Run only Environment
Secret On, Off Off; On for a new row whose name or path contains token, secret, password, key or session
If missing Keep the old value, Clear the variable, Fail the request Keep the old value

Set variable options

Section titled “Set variable options”
Option Values Default
Target Run only, Environment (only written while the workspace's scripts are on) Run only
Secret On, Off Off; a value using a secret is secret

Skip if operators

Section titled “Skip if operators”

is empty (default), is not empty, equals, does not equal.

Generators (Before row values)

Section titled “Generators (Before row values)”
Generator Input Output
{{$uuid}} / {{$guid}} — v4 UUID
{{$timestamp}} — Unix seconds
{{$timestampMs}} — Unix milliseconds
{{$isoTimestamp}} — ISO 8601 UTC
{{$randomInt}} — 0–999
{{$randomInt low high}} Two integers A number in the range, both ends included
{{$randomText n}} Length (default 16, at most 4,096) Letters and digits
{{$base64 text}} Text Standard base64
{{$sha256 text}} Text Lower-case hex
{{$hmacSha256 key message}} Key (up to the first space), message Lower-case hex HMAC-SHA256

Inside generator inputs: \n = line break, \t = tab; {{method}}, {{path}}, {{url}}, {{body}} are the request-level.

Statuses

Section titled “Statuses”
Status Meaning Counts as passed
passed The check held Yes
failed The check did not hold, or could not be read No
not evaluated It could not run (body too large, an earlier level failed, scripts off) No
error A script error No
extracted / not extracted An extraction's outcome Not counted as a check

Limits

Section titled “Limits”
Limit Value
JSON path and JSON body checks Bodies up to 16 MB
Regex Linear-time engine; no look-around or back-references
XML paths Local-name matching; positions, *, @attr, text() only
Values shown in messages 80 characters
