Complete settings reference

Open Settings with the gear at the bottom of the activity bar, Ctrl+,, or Settings: Open. Settings float over the window: categories on the left, the chosen one's settings on the right. Up and Down choose a category. Esc, ×, or a click outside closes it. Changes apply immediately and are remembered on this computer.

A stored value that is invalid or out of range goes back to its default, and LynxQ API says which setting it reset.

General

Section titled “General”

How LynxQ starts and closes.

Setting Default Values Effect
Restore previous tabs On On / Off Reopen last session's tabs
Confirm before closing unsaved tabs On On / Off Off closes them immediately. Ctrl+Shift+T still reopens them.
Default environment on startup Last used None, Last used, any environment Which environment is active when LynxQ API starts
Show Beta features On On / Off Shows the Performance Lab and Mock Server, and their commands
Group OpenAPI imports by tag On On / Off Each operation in a folder named after its first tag; untagged ones at the top
Workspace folder %USERPROFILE%\LynxQ Workspace A folder Open folder, Change…

Network

Section titled “Network”

Timeouts, redirects, proxy, certificates and cookies for every request sent.

Setting Default Values Effect
Request timeout 60 0–3600 s 0 waits as long as it takes
Follow redirects On On / Off Off shows the 3xx response
Maximum redirects 10 0–50
Proxy System proxy System proxy, No proxy, Custom Change… opens the proxy dialog
Verify TLS certificates On On / Off Off: the status bar shows TLS: unverified in red
Custom CA certificate file None PEM or DER file Trusted by LynxQ API as well as the system's. Choose…, Remove.
Allow http token server on localhost Off On / Off Lets an OAuth 2.0 token server on localhost, 127.0.0.1 or ::1 use http. Never enabled by an import.
Send cookies automatically On On / Off Keeps cookies in memory until LynxQ API closes, and sends them back
Clear cookies — Button Forgets every cookie kept so far
Confirm before sending to PROD On On / Off Asks before Send or a collection run goes to PROD

Response and editor

Section titled “Response and editor”

How responses and bodies are shown.

Setting Default Values Effect
Pretty-print JSON On On / Off Off shows JSON as received
Word wrap Off On / Off Wraps long lines in the response and the body editor. Text over 256 KB is not wrapped.
Large response limit 10 1–256 MB A larger response is not downloaded. Send & Download is not limited by it.

Privacy and security

Section titled “Privacy and security”

How secrets are shown and kept.

Setting Default Effect
Mask secrets in the UI On Shows passwords, tokens and secret variables as dots. The eye shows one.
Do not save secret values in history Always on History keeps {{placeholders}}, never passwords, tokens or secret values. Can't be turned off.

History

Section titled “History”
Setting Default Values
Save request history On Off keeps no sent requests
Maximum entries 1,000 10–100,000. The oldest are dropped first.
Clear history — Removes all entries

Scripts

Section titled “Scripts”

These apply to the current workspace and are kept on this computer.

Setting Default Effect
Run scripts in this workspace Off Turns JavaScript scripts on for this workspace
Do not ask about scripts changed on disk Off A script changed by a pull runs as found. New and imported scripts still wait for review.
Review the workspace's scripts — Review scripts…: every script, read-only, each with Turn on
